Option compatibility
====================

TOML configuration workflows accept the integrated generation, execution, comparison, plotting, rotation, and related model controls documented by ``expreccs --help``. Existing-deck workflows accept regional-to-site mapping controls including skipped entries, interpolation frequency, telescopic coefficient, pressure representation, FIPNUM mapping, and irregular contours.

Run ``expreccs --help`` for the exact names and defaults in the installed release.
